BlazeJ2ME

A single-file browser runtime for Java ME/MIDlet compatibility research, focused on classic CLDC/MIDP applications and low-resource browser environments.

Implemented areas

JAR/JAD loading, class/runtime interpretation, MIDP display/input experiments, RMS-style persistence, diagnostics, audio and selected Nokia-style compatibility handling.

Publication boundary

No commercial JAR/JAD is bundled. The runtime includes its third-party DEFLATE component with the upstream MIT notice preserved.

Status

Experimental. Compatibility varies by MIDP profile, vendor APIs, bytecode patterns, media requirements and browser behavior.

Use only applications you are entitled to run. This project is a compatibility study, not a complete Java ME device implementation.
