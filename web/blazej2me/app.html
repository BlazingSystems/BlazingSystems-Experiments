Standard Nokia device codes are preserved: Up −1, Down −2, Left −3, Right −4, Fire/centre −5, Soft 1 −6, Soft 2 −7; number keys remain 0–9, * and #. Host keyboard default: arrows, Enter/Space, Q/W, 0–9, E=* and R=#. Choose Custom to remap every host key.

Unsupported Java bytecodes and unimplemented J2ME APIs are reported here with class, method and program counter whenever possible.

BlazeJ2ME v1.6 universal compatibility fix is a self-contained browser J2ME/MIDlet runtime focused on old ChromeOS and low-end devices.

Current target: CLDC/MIDP Canvas/GameCanvas titles, including common Nokia UI API games. The JVM core implements common classic Java bytecodes, class loading, threads, basic java.lang/java.util/java.io services, LCDUI drawing, keypad input, resources and RMS-style persistent records. 3D/M3G and advanced media are not yet complete. Common Nokia UI extensions are handled natively. This build includes synchronous PNG decoding for J2ME resources, corrected Nokia DirectGraphics manipulation order, corrected MIDP drawRegion transforms, optional WebGL hardware-accelerated presentation with normally accelerated Canvas2D and compatibility fallback, short-slice adaptive JVM scheduling for smoother animation, correct wrapper-stream delegation, and lower idle CPU, Object wait/notify support, broader LCDUI TextBox/TextField/Form support, RMS enumeration/capacity APIs, a JSR-256 acceleration-sensor bridge with keyboard tilt fallback, safer image semantics, basic GCF file/network connection stubs, inherited-field resolution fixes, automatic classic-screen detection, Standard Nokia key codes with custom host-key mapping, Nokia OTA tones, MMAPI MIDI playback, and low-load rolling audio schedulers for old devices.

Embedded DEFLATE support uses Pako (MIT license). No game ROM/JAR content is bundled.
