BlazeAPK

A browser-based APK/DEX parsing and Android compatibility-layer experiment. The project explores how selected Java-side Android application behavior can be interpreted inside an offline HTML sandbox.

Current runnable build

Beta 0.6
Recovered single-file artifact; JavaScript parser validation passed. Beta 0.7 currently exists as design/implementation documentation, not as a verified runnable release.

Implemented areas

APK/ZIP parsing, multi-DEX discovery, selected Dalvik interpretation, resource/layout handling, high-level Android API stubs, lifecycle/input experiments and browser-local persistence.

Compatibility boundary

This is not ART/AOSP. Native JNI libraries, Binder, complete OpenGL/SurfaceFlinger behavior, Play Services, DRM and many framework APIs remain outside the implemented runtime.

Publication boundary

No third-party commercial APK is bundled. Testing fixtures should be original, redistributable or user-supplied.

Experimental compatibility research only. A successful package scan does not mean an application will run correctly.
