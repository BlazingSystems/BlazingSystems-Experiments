# User guide

Download the v1.1.0 verified prerelease ZIP, extract it, then double-click Create.exe. On Application Discovery, choose a registered app, extracted folder, or EXE. The whole directory containing the selected executable is used as the copy root. Review Analyzer findings. Choose a **new nonexistent** destination under Portable Builder. Conversion is copy-first; original files remain untouched. A per-client data mode **with the diskless-safe local copy enabled** is safest for network-shared game roots if the client has persistent writable storage. Test the generated EXE on a clean client.

Profile editor imports and exports JSON definitions. Automatic profile matching/application is not implemented. Modify advanced version settings in PortableConfig.json with suitable technical experience.
