# Experimental Software Notice

This repository contains proof-of-concept and compatibility research.

Public examples contain no production credentials, customer records, employer records, private keys, or proprietary operational datasets. Test packages, sample identifiers, and network values should be treated as demonstration material only.

Recovered experimental work may be published as a sanitized derivative instead of the raw original. Private originals are kept outside public GitHub when they are safe to retain. Commercial APKs, JARs, ROMs, BIOS files, copied application payloads, and other third-party binaries are not distributed as part of the portfolio.

Compatibility experiments are not substitutes for the original operating systems, runtimes, device-management platforms, or vendor software they study. Third-party components remain subject to their own licenses.
