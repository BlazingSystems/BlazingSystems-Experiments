# EasyMode Installers

Installer families for different operator environments.

- [Offline HTML](offline-html/) — browser-guided connection/bootstrap workflow
- [OpenWrt](openwrt/) — native shell installer/rollback
- [Windows](windows/) — PowerShell-assisted upload/install workflow

Installers are expected to check prerequisites and fail clearly rather than pretending unsupported browser or transport capabilities exist.
