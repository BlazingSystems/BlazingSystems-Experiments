# EasyMode Editions

Hardware-oriented presentation/configuration profiles built on the same EasyMode core.

| Edition | Intended target |
|---|---|
| [Cellular](cellular/) | OpenWrt devices with cellular capability |
| [AP](ap/) | Access points and limited-port devices |
| [Router](router/) | General Wi-Fi routers |
| [Switch](switch/) | Wi-Fi-less OpenWrt switches |
| [PC](pc/) | Expandable x86/PC systems |
| [Generic](generic/) | Minimal broadly applicable interface |

Edition manifests describe capability assumptions; hardware validation remains device-specific.
