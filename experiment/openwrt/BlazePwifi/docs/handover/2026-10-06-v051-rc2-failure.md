## Result

RC2 was **not releasable**.

The v0.3 foundation gate passed, confirming the RC1 compatibility fix.

Validation then failed at **Admin security validation** because the admin CGI unconditionally sourced the new Rental-update library from the production path:

`/usr/lib/blazepwifi/rental_update.sh`

The isolated security test intentionally supplies only its required libraries through test-path environment variables, so the CGI terminated before exercising auth/CSRF status logic.

This was a module-loading integration error, not a weakening or failure of authentication, lockout, CSRF or session controls.

## Fix

Admin CGI now:
- conditionally sources the Rental-update module when present;
- explicitly requires the module only inside `rental_update_get` / `rental_update_set`;
- preserves all existing role, password-change and CSRF protections on those actions.

Fix commit:
`5be2559255ae9f01a6d2326abe39660a0847c9dc`
