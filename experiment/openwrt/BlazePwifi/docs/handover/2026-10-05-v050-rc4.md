# Handover Log — 2026-10-05 — v0.5.0 RC4

## Why RC4 exists

RC3 successfully reached the real Device Owner launcher flow, but the emulator proved the secret timer hold could be lost on a busy/old Android UI thread.

Evidence:
- Android APK built and installed.
- Device Owner was successfully set.
- BlazeRental locked page rendered correctly.
- Unpaid app-drawer and horizontal escape checks passed.
- A 4.5-second hold on the `00:00:00` timer did not open `BlazeRental Initial Setup`.

The timer touch listener previously depended only on a delayed Handler callback. If that callback had not been dispatched before ACTION_UP, ACTION_UP removed it and discarded the completed hold.

## Fix

Updated:
`android/BlazeRentalLauncher/src/com/blazesystems/blazerental/RentalSystemPages.java`

Behavior now:
- delayed hold callback remains the normal path;
- ACTION_UP removes the pending callback and checks `adminGesture.onUp(...)`;
- if the configured hold threshold was completed but the callback was delayed, ACTION_UP opens BlazeRental Admin;
- ACTION_CANCEL explicitly cancels and can never open admin.

Implementation commit:
`1de5845f47afe1924d26b6fb133c5130c092ba32`

RC4 branch:
`blazepwifi-v0.5.0-rc4`

RC4 includes the previous icon, browser-route and emulator-HOME fixes.
