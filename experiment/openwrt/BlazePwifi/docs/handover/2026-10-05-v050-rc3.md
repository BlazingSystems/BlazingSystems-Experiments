# Handover Log — 2026-10-05 — v0.5.0 RC3

## Why RC3 exists

RC1 Android Device Owner emulator job failed before the APK test actually started.

Root cause was in the v0.5 audit harness:

`android_v05_audit.sh` assigned the launcher component to Bash variable `HOME`.

That replaced the runner's normal home directory, so ADB attempted to create its configuration directory beneath the launcher component string and aborted:

`Cannot mkdir 'com.blazesystems.blazerental.debug/com.google.android.apps.nexuslauncher.NexusLauncherActivity/.android'`

This was an audit-harness environment bug, not evidence of a BlazeRental application crash or Device Owner bypass.

## Fix

Renamed the audit variable from `HOME` to `HOME_COMPONENT` and updated launcher-start references.

Implementation commit:
`9bb91bc9d33bb61012ff2fb20633fb0a496a5c70`

RC3 branch:
`blazepwifi-v0.5.0-rc3`

RC3 also contains the RC2 browser-audit fix that routes voucher testing through the new Vouchers & Rates console page.
