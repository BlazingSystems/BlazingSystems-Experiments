# BlazePwifi portal template gallery

Open `index.html` in any browser. No router, API, or internet connection is required.

The captive portal keeps the first view intentionally simple: remaining time, coin purchase, voucher, and rates. Non-sensitive device/network information lives below the primary actions.

Included previews:

- `admin-login.html`
- `admin-dashboard.html`
- `portal-home.html`
- `rates.html`
- `insert-coin.html`
- `vendo-select.html`
- `voucher.html`
- `active-session.html`
- `pause-resume.html`
- `vendo-setup.html`
- `controller-setup.html`
- `rental-enrollment.html`
- `rental-locked.html`
- `error-offline.html`

`template.json` is the portable base design definition used by the portal builder.
