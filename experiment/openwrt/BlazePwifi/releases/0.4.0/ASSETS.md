| Target | Required output |
|---|---|
| Android | BlazeRental.apk, signing certificate/fingerprint, SHA256 |
| ESP8266 | BlazePwifiVendo binary + INO + SHA256SUMS |
| ESP32 | BlazePwifiVendo32 binary + INO + SHA256SUMS |
| Ruijie RG-EW1200G Pro v1.1 | OpenWrt firmware/sysupgrade image + SHA256SUMS |
| x86_64 | BIOS/UEFI-capable raw/compressed OpenWrt disk image(s) + SHA256SUMS |
| Orange Pi Zero 3 | disk image + SHA256SUMS |
| Orange Pi One | disk image + SHA256SUMS |
| Orange Pi PC | disk image + SHA256SUMS |

Additional Orange Pi family assets may be included when their independent validation passes.

Simulation evidence should include machine-readable audit output and logs/screenshots where the environment supports them. Structural inspection is not to be described as physical-board boot testing.
