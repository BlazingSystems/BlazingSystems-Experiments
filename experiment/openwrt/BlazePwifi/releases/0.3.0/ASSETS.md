# Production assets

The GitHub Release for v0.3.0 carries the installation-ready outputs. Primary files are BlazeRental.apk, BlazeRental-QR-Setup.html, ESP8266/ESP32 firmware BIN/INO files, OpenWrt router/SBC/x86 IMG.GZ/BIN files, source TAR.GZ, per-target ZIP bundles, checksums and manifest.

x86 and Orange Pi use raw disk images rather than an ISO because that is the native OpenWrt installation format for these targets.
