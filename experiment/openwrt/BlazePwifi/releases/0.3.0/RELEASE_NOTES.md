# BlazePwifi 0.3.0

Production software release for supported BlazePwifi targets.

Highlights:
- prepaid captive portal and server-authoritative accounting;
- hardened HTTPS admin authentication with lockouts, roles, CSRF protection and audit trail;
- portal builder and lightweight Tabler-based Standard/Full administration shell;
- ESP8266 and ESP32 coinslot firmware with durable coin journal, verified Wi-Fi setup, reconnect fallback and server-managed runtime policy;
- Orange Pi Zero 3, One and PC images plus successful optional Orange Pi profiles;
- x86_64 BIOS and UEFI images;
- Ruijie RG-EW1200G Pro v1.1 image set;
- BlazeRental coin-operated Android kiosk with Device Owner QR provisioning, paid-app allowlist, server-controlled lease, administrator password verifier and rental coinslot targeting;
- self-contained PC QR Setup HTML generated against the exact signed APK checksum.

The release artifacts are compiled and installation-ready. Physical deployments still require exact-board recovery/electrical validation before commercial rollout.
