# BlazePwifi 0.3.0-rc.1 release index

This folder is the source-controlled index for the v0.3.0 release candidate.

Large generated firmware and application binaries are attached to the matching GitHub Release instead of being committed into Git history. The release workflow also uploads direct installer files and per-target ZIP archives.

## Mandatory build targets

- Ruijie RG-EW1200G Pro v1.1
- x86_64 legacy BIOS
- x86_64 UEFI
- Orange Pi Zero 3
- Orange Pi One
- Orange Pi PC
- ESP8266 Vendo
- ESP32 Vendo
- BlazeRental Android APK

## Additional Orange Pi builds

The workflow also attempts PC Plus, PC2, Zero, Zero2, Zero2W, and One Plus. Only successful files are published.

Read `ASSETS.md` for the expected asset families and `RELEASE_NOTES.md` for validation boundaries.
