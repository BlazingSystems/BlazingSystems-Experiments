# v0.5.2-rental.2-rc.6

RC6 provisioning candidate.

Key changes over RC5:

- repeated identical Android provisioning callbacks preserve in-progress state;
- Standard Enrollment cannot overwrite an already-bound permanent identity;
- explicit Transfer is required before rebind;
- scanner state errors are differentiated correctly;
- Android versionCode 50207 / versionName 0.5.2-rental.2-rc.6.

See the main release notes under `releases/0.5.2-rental.2-rc.6/README.md` and `PROVISIONING-AUDIT.md`.


Additional durability hardening:
- expired/malformed abandoned enrollment rows are garbage-collected before new token creation;
- active one-time enrollment rows are bounded to prevent storage exhaustion;
- QR generation fails closed if token creation cannot be durably completed.
