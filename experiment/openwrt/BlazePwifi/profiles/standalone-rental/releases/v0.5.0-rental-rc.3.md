# v0.5.0-rental-rc.3

**Status:** Latest Rental release candidate

## Windows OneClick hotfix

rc.2 correctly detected a first-time PuTTY SSH host key, but Windows PowerShell 5.1 could convert PuTTY's stderr into a terminating `NativeCommandError` because the installer uses `$ErrorActionPreference = "Stop"`.

rc.3 routes all plink/pscp calls through native-command wrappers that temporarily allow native stderr, capture the real exit code and output, and then restore strict PowerShell error handling.

Expected first connection now:

```
Double-click BAT
→ enter router IP / SSH credentials
→ new host key detected
→ GUI shows fingerprint and asks Trust?
→ Yes
→ SSH is fingerprint-pinned for upload/install
→ installation continues
```

No manual PuTTY launch or pre-caching is required.

The Standalone Rental architecture remains unchanged from rc.2.
