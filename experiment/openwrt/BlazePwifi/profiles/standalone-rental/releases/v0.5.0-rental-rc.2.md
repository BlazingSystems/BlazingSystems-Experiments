# v0.5.0-rental-rc.2

**Status:** Latest Rental release candidate  
**Published:** October 6, 2026  
**GitHub Release:** https://github.com/BlazingSystems/BlazingSystems-Experiments/releases/tag/v0.5.0-rental-rc.2

rc.2 supersedes the rc.1 ESP multi-slot design and aligns the release with the finalized Standalone Rental architecture.

## Main changes

- OpenWrt Rental administration at `https://LocalIP/rental/`.
- Android rental server uses `http://LocalIP` and `/cgi-bin/rental`.
- Existing router root/basic/advanced administration routes are preserved.
- Standalone installation does not write OpenWrt `network`, `wireless`, or `firewall` UCI packages.
- Windows OneClick SSH installer is the primary existing-router deployment path.
- ESP8266/ESP32 use one root admin console.
- Three ESP modes: Rental Server, Rental Server + one local coinslot, Remote Coin Slot Interface.
- One physical coinslot per ESP by default.
- Rental Server modes can bind additional remote ESP coinslot interfaces.
- Five failed saved-Wi-Fi attempts trigger ESP recovery AP.
- Internet/DNS failure alone does not stop the reachable local rental service.
- Full BlazePwifi conversion remains explicit and backs up configuration first.
