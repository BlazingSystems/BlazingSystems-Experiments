Updates & Recovery

Install feature/revision updates without reflashing, keep the previous stable version, and roll back safely.

Version state

Rollback target—

Install update bundle

Normal feature updates are applied transactionally to the writable overlay. Exact SHA-256 verification is required before activation.

Safety model: the previous stable files remain available while the new candidate proves healthy. Failed immediate health checks roll back automatically; boot health failures also trigger rollback. Full firmware flashing remains available only for base-OS/kernel/partition changes that cannot be delivered safely as an overlay update.
