# BlazePwifi Offline UI Preview

This folder contains offline mockups for the planned BlazePwifi Management Console and customer/rental Insert Coin experiences.

## Download

- `BlazePwifi_Offline_Management_Console_Preview.zip`

The ZIP contains a single self-contained HTML file. It has no Bootstrap, CDN, or external runtime dependency.

## Mock login

- Username: `admin`
- Password: `blaze1234`

## Preview scope

The HTML demonstrates the planned Management Console shell plus interactive PisoWiFi and BlazeRental Insert Coin previews. It is a UI/UX mockup only and does not change production BlazePwifi behavior.

The production default portal remains a separate, undeletable/fallback concept in the active BlazePwifi design.
